# TweakMB Reborn

ℹ️ Inspired by [TweakMB](https://www.nexusmods.com/mbwarband/mods/1751).

⚠️ This tool is _only_ compatible with **Mount & Blade: Warband Native**'s latest Steam version **v1.174**, which the discontinued original **TweakMB** does not support. For older versions and other games, use **TweakMB** instead.

⚠️ This tool is currently **experimental** and _most_ tweaks are still **untested**! Use at your own risk, backup your save files before using, and use Steam's **verify integrity of game files** ~~if~~ when something breaks (and restoring defaults via the tool doesn't fix it).
